# 模拟交易：申赎费率与净值公布即结算 — 需求文档

> 目标读者：产品 / 运营 / 测试
> 关联模块：基金雷达 · 模拟组合（simulated portfolio）

## 1. 背景与问题

用户反馈：项目中"我昨天的收益"与支付宝实际基金收益对不上。

排查结论（2026-09-19）：**不是数据缺失，而是模拟规则本身与真实基金规则不一致**，具体有三处：

1. **收益晚一天**。模拟要求订单"最早下一交易日确认"后才更新估值。9-18（周五）上午 10:00 的定投订单确认日被算到 9-21（周一），于是 9-18 晚上的净值虽然已公布入库，但 22 只基金的估值被冻结在 9-17。用户 9-19 看到的"最近一期收益"是 9-17 的，支付宝显示的是 9-18 的。
2. **没算手续费**。模拟买入按全额申购金额换算份额、卖出按全额净值到账。真实基金要扣申购费（A 类）和赎回费（分档），支付宝的收益里已经包含了这些费用。
3. **深夜净值滞后**。净值同步只在 7:00 / 20:00 / 22:00 三个时间点触发。22:00 之后才公布净值的基金，要等到次日 7:00 才结算。

## 2. 目标

让模拟组合的**收益口径与支付宝（真实场外基金）对齐**：

1. 每个交易日晚上净值公布后（约 20:00~24:00，多数基金 20:30 前后），当晚就算出当日涨跌，用户睡前看到的就是当天收益；
2. 申购费、赎回费按真实规则扣减，收益数字含费用；
3. 9-18 起的历史账目自动按新规则重算，9-17 及以前已确认的账目保持不变。

## 3. 需求范围

| 编号 | 需求 | 说明 |
|---|---|---|
| R1 | 定投/手动买入按 T+n 规则确认 | T 日 15:00 前下单 → 按 T 日净值确认份额；份额 T+1 个交易日可用（可卖） |
| R2 | 净值公布即结算 | 不等待"确认日"，T 日净值一经公布入库，当晚结算即按 T 日净值确认订单并更新当日涨跌 |
| R3 | 申购费模拟 | 净申购金额 = 申购金额 ÷ (1 + 申购费率)；份额 = 净申购金额 ÷ T 日净值；申购费 = 申购金额 − 净申购金额 |
| R4 | 赎回费模拟 | 卖出按净值总额 × 赎回费率扣费；费率按**批次持有天数**分档（C 类：<7 天 1.5%，7~30 天 0.5%，≥30 天 0；A 类按该基金实际费率） |
| R5 | 费率数据来源 | 配置表（sim_fee_rule）+ 天天基金 f10 页面初始化抓取 + 后台人工可维护 |
| R6 | 历史重算 | 9-18（含）起的 PENDING 订单升级为新规则并自动确认重算；9-17 及以前已确认订单与流水保持原结果不动 |
| R7 | 深夜净值兜底 | 净值同步增加深夜窗口（0:00~0:59），保证当晚 24:00 前公布的净值当晚结算 |
| R8 | 规则声明更新 | 前端"模拟规则"文案同步为新口径，用户可见 |

## 4. 非目标（本期不做）

- 不模拟基金管理费 / 托管费 / 销售服务费（这些已包含在每日净值里，支付宝收益口径同样不单列）；
- 不模拟 QDII 基金（T+1/T+2 公布净值）与货币基金，本期组合内无此类基金；
- 不模拟渠道限购、临时暂停申购、大额赎回限制；
- 不修改 9-17 及以前已确认订单的历史成交（按用户拍板：历史已确认订单不动）。

## 5. 业务规则说明（供产品/测试理解）

### 5.1 订单确认时点

- 模拟下单仍遵循 15:00 截止：15:00 前下单按当日净值，15:00 后按下一交易日净值；
- 订单从"待确认"变为"已确认"的时点是**净值公布时**，不再等下一交易日；
- "份额可用（可卖）"仍按 T+1 交易日：T 日买入的份额，T 日当晚显示在持仓里，但次日才可卖出。

### 5.2 赎回费分档的"持有天数"

- 从买入批次确认日（T 日）起，到卖出申请日止，按**自然日**计算；
- 示例：9-18 买入，9-21 卖出 → 持有 3 天（自然日）→ 不足 7 天，赎回费 1.5%；
- 分批买入时按"先进先出"，每一笔批次单独计档。

### 5.3 收益口径

- 当日涨跌 = 当日市值变化（含费用影响），相邻交易日之间计算；
- 累计收益 = 当前市值 − 累计投入 + 累计净赎回收入 + 累计分红（资金流中性口径，与支付宝"持有收益+累计收益"对齐）。

## 6. 验收标准

1. 净值入库当晚（模拟环境重放 9-18 数据）：22 只基金估值日期更新为 9-18，当日涨跌与支付宝 9-18 收益同方向、量级一致；
2. 前端"最近一期收益"日期为最近已公布净值日，不再停在上一交易日；
3. 一笔 100 元 A 类基金（申购费 0.08%）买入后，份额 ≈ 99.92 ÷ 当日净值，订单执行详情可见费用；
4. 买入后 3 天内卖出的份额按 1.5% 扣赎回费，30 天后卖出不扣费（C 类）；
5. 后台费率维护页可修改某基金申购/赎回费率，保存后新订单生效；
6. 9-17 及以前的历史收益曲线、已确认订单金额不发生变化。
