# 本人条件参与建议的实现记录

实现文件：HoldingAdvicePolicy、HoldingAdviceService、DecisionControllerV2、DecisionServiceV2及前端DecisionPanelV2、历史接口和设置文案。

新个人输入由同一条SQL读取。资金安排排序与统一仓储保持一致，账本日期兼容既有数组序列化。只在Java中使用个人数据，公共基金服务仍只收到基金代码和查询日期。

数据库不新增迁移，不修改旧建议、资金安排或交易记录。新增建议沿用不可变档案表，策略版本变化形成新内容身份。V4保留最新回退显示及独立历史查询，标为旧规则；手动生成仅允许正份额持仓。

验证：隔离单元测试覆盖偏好改变实际结论、长线不以五日替代半年、资金未知/撤销/未来、用款临近、复查到期、金额与百分比损失限制、信息不完整、冻结/待卖/清仓、保存中偏好或资金变更拒绝，以及旧建议原文保留。只读数据库SQL核对实际个人输入结构、资金安排与统一最新记录一致，历史建议未写入。

当前限制：真实现金余额未记录，不能输出追加买入建议；不能核实真实渠道申赎与到账，故不输出精确交易数量。规则尚无整体投资效果验证，不承诺收益。浏览器画面与已登录端到端保存另行验收。

联动检查：Python正式建议核验及既有每日建议服务共用的版本常量同步V5，防止服务已生成新版本而核验仍认V4。未改变定时任务开关或执行范围。前端增加处理中读屏状态。

真实读回发现账户包含不同市场、净值日期不同的基金。本轮当前持有亏损核对沿用页面各基金最近已公布估值，不把日期不同直接视为缺失；明确不代表同日历史回撤。缺失/未来日期或估值异常仍阻止通过。增加相关回归。
